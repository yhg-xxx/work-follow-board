# 色彩系统规范 · 工作跟进看板

> 定义工作跟进看板的色彩语言：色板、语义令牌、使用场景、可访问性。
> 所有颜色以 **语义令牌（CSS 变量）** 形式落地，详见 `src/assets/base.css`。

---

## 一、设计原则

1. **蓝白台账风**：以「墨蓝 + 纸白」为主轴，传递稳重、清晰、台账式的秩序感。
2. **语义优先**：组件只引用语义令牌（`--c-*`），不直接写色值；主题切换时令牌整体重映射。
3. **同色系双主题**：深色不是「反色」，而是同色系的「墨蓝夜色版」，保留品牌一致性。
4. **可访问性**：正文 / 标题对比度满足 WCAG 2.1 **AA**（正常正文 ≥ 4.5:1，大字 ≥ 3:1）。

---

## 二、令牌架构（两层）

```
原始色阶 Primitive（原料，不随主题变）
        │  组合 / 映射
        ▼
语义令牌 Semantic（业务真正用，随主题整体切换）
```

- **原始色阶**：`--blue-50…900`、`--gray-50…700`、`--red/green/amber/slate-500`、看板身份色。
- **语义令牌**：`--c-bg`、`--c-card`、`--c-ink`、`--c-blue`、`--c-st-urgent` …，是组件**唯一**应引用的层。

> 原始色阶只为语义层提供「原料」与色板一致性；**组件中不要直接用 `--blue-500`**，请用 `--c-blue`。

## 四、表面层级（Surface Hierarchy）

层级靠「明度阶梯」表达，谁更亮谁更靠前。

**浅色主题**：侧栏(最深 `#0F1B3D`) → 应用底(`#F2F6FD`) → 卡片(最亮 `#FFFFFF`)
**深色主题**：侧栏(最深 `#060A16`) → 应用底(`#0D1426`) → 卡片(最亮 `#172139`)

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--c-bg` | `#F2F6FD` | `#0D1426` | 页面底色 |
| `--c-card` | `#FFFFFF` | `#172139` | 卡片 / 数据区 / 弹窗 |
| `--c-line` | `#DFE8F8` | `#2A3654` | 普通分隔线 |
| `--c-line-strong` | `#C7D5F0` | `#3D4D70` | 强分隔 / 虚线描边 |

## 六、使用规范

### ✅ 应该

```css
.title { color: var(--c-ink); }
.btn-primary { background: var(--c-blue); }
.row:hover { background: var(--c-row-hover); }
.tag-urgent { color: var(--c-st-urgent); background: var(--c-st-urgent-soft); }
```

### ❌ 避免

```css
.title { color: #16223E; }          /* 硬编码，深色下不变 → 失败 */
.row:hover { background: #EAF1FE; } /* 硬编码，深色下发灰 */
.btn { background: var(--blue-500);}/* 越过语义层直接取原料 */
```

### 文字对比度（关键组合，均 ≥ AA）

| 组合 | 浅色对比度 | 深色对比度 |
|---|---|---|
| `--c-ink` / `--c-bg` | ≈ 13.5:1 ✅ | ≈ 13.8:1 ✅ |
| `--c-ink` / `--c-card` | ≈ 15.3:1 ✅ | ≈ 11.2:1 ✅ |
| `--c-muted` / `--c-card` | ≈ 4.8:1 ✅ | ≈ 5.9:1 ✅ |
| `--c-blue` / `--c-card` | ≈ 6.0:1 ✅ | ≈ 5.4:1 ✅ |
| `--c-st-urgent` / `--c-card` | ≈ 4.2:1（大字/徽章 ✅） | ≈ 4.6:1 ✅ |

> 状态色用于「徽章 + 软底」场景时，因底色同色系且字号偏小，建议**加粗**或搭配图标以保证辨识。

## 七、新增颜色的流程

1. 先判断是否可复用现有语义令牌；能复用就不新增。
2. 确需新色 → 加到**原始色阶**（如 `--blue-550`），再在 `:root` 与 `[data-theme="dark"]` 各映射一个**语义令牌**。
3. 同步更新本表的「用途」与「使用场景」。
4. 自测两个主题下的对比度（推荐浏览器 DevTools 的对比度提示）。
